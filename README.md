Calculator with reverse Polish notation as a starter project that I use to learn Kotlin.
Hosted on replit https://replit.com/@jdonges1/RPNCalc

Supported operations: `+`, `-`, `*`, `/`, `sqr`, `exp`, `sin`, `cos`, `pow`.

Example:
```
Input>9 sqr 18 + 3 /
33.0
Input>3 * 1 +
100.0
Input>2 3 pow
8.0
Input>0.5 sin
0.4794255386
Input>exit
```
